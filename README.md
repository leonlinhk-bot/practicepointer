> 香港保險中介人的執業基礎設施 —— 由從業者共建、向全行業開放的公共品。

### 條文索引的原則

本站**不轉載法例原文**，只提供「章號 + 條號 + 一句摘要 + 官方原文連結」。

理由有兩條：
1. 法例會修訂，抄一份在站上就會過期；
2. 項目未有持牌人覆核之前，轉載只會放大風險。

所有條號僅作**定位提示**，使用前請回到官方原文核對。

## 參與方式：從「糾錯」開始

寫一篇文章要一小時，**糾錯只要三分鐘** —— 而糾錯恰恰最能看出一個人專不專業、正不正念。

1. **糾錯** → 看到講得不準，點「提交糾錯」開一個 issue
2. **採納** → 經討論採納後併入
3. **署名** → 進貢獻者牆

詳見 [`CONTRIBUTING.md`](CONTRIBUTING.md)。
